# IconControls-For-WinForms

**IconControls-For-WinForms** is a library for **Windows Forms projects in C#** that provides **custom controls with built-in icon support**, allowing you to create modern and visually appealing interfaces with ease.

![Demo](https://kevinalex2000.github.io/Controls-FontAwesome-for-Windows-Forms/docs/imgs/intro.gif "Demo")

---

## 🚀 Main Features

- Ready-to-use custom controls
- Buttons, labels, and other components with icon support
- Easy to implement and customize
- Designed for .NET desktop applications (WinForms)
